# Hit the Pose

A pose-timing camera game for new photographers. AI 101, Project 4. Concept and direction by Russell McCord; code by Claude.

**Play:** https://usartfoto.github.io/hit-the-pose/ (current game) · [v3](https://usartfoto.github.io/hit-the-pose/v3.html) (Cycle 1 build)

The real example photos (Jane Allan, The Lens Lounge) show only in the local class build; this public copy links to the guide instead. three.js is MIT licensed (see `assets/lib/three/LICENSE`).
