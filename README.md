# Hit the Pose

A pose-timing camera game for new photographers. AI 101, Project 4. Concept and direction by Russell McCord; code by Claude.

**Play:** https://usartfoto.github.io/hit-the-pose/ (current game) · [v3](https://usartfoto.github.io/hit-the-pose/v3.html) (Cycle 1 build)

Example photos on the review card: Jane Allan, The Lens Lounge, ["49 best female standing poses"](https://thelenslounge.com/female-photography-standing-poses/), shown for educational use (SCAD AI 101 class project) with citation and a link on every card. three.js is MIT licensed (see `assets/lib/three/LICENSE`).
